# Telecom Customer Churn Analysis

## Project Overview
This project analyzes telecom customer data to identify churn patterns, understand customer behavior, and discover factors associated with customer attrition.

## Tools & Technologies
- SQL (MySQL)
- Microsoft Excel
- Power BI

## Dataset Overview
- Total Customers: 2,850
- Churned Customers: 446
- Active Customers: 2,404
- Overall Churn Rate: 15.65%

## Key Business Insights
- Customers with complaints had an 82.61% churn rate.
- Customers without complaints had a 9.77% churn rate.
- Tariff Plan 1 showed a higher churn rate than Tariff Plan 2.
- Low-usage customer segments showed higher churn rates than high-usage customers.
- Customer churn was also analyzed by age group and subscription length.

## Project Work
- Data cleaning and preparation
- SQL queries for customer churn analysis
- KPI calculations and customer segmentation
- Excel-based data analysis
- Interactive Power BI dashboard

## Project Files
- SQL Analysis Script
- Cleaned Customer Dataset
- Power BI Dashboard

## Objective
To identify customer segments associated with higher churn and generate actionable insights that can support better customer retention strategies.
